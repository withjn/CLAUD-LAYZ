# CLAUD-LAYZ

Notes for making layZ videos with Claude Code, kept here so they follow me to any machine.

**Claude: read this file and every file in `reels/` before starting a new layZ video.**

## Standing preferences

- Format: 9:16, 1080x1920, 45–60 s.
- Voice: **Liam** — `TX3LPaxmHKxFdv7VOQHJ` ("Liam - Energetic, Social Media Creator"), not the Afrikaans Liam.
- **No captions or subtitles.**
- **No sound effects** unless I ask; if I do, keep them quiet and simple.
- No trivia / "earned fact" lines in scripts. Go easy on sentences starting with "But".
- Lots of camera movement, but nothing may block the view of the character.
- Final 3D render at **30 fps**.
- Target bitrate 15–18 Mbps (layZ "high" export only reaches ~13.4 Mbps — re-encode with ffmpeg if needed).
- Guided mode: show me the script and the scene plan first; I give timestamped fixes.
- Crude humour is fine when I ask for it, but never explicit (pixelate, clothes stay on).
